## 🌟 Featured Project

### [ESP32-S3 Voice-Controlled LEDs using Edge Impulse](https://studio.edgeimpulse.com/studio/1061475)
A real-time TinyML keyword-spotting system deployed on an **ESP32-S3 N16R8** microcontroller.
- **Audio Preprocessing:** Mel-Frequency Energy (MFE) filterbank (16 kHz, 1-second window)
- **Model:** Transfer learning on MobileNetV1 (0.1), INT8 Quantized
- **Validation Accuracy:** **95.5%** (F1: `one` 0.98, `two` 0.94, `three` 0.94)
- **On-Device Inference:** **271 ms** latency, **36.5 KB** peak RAM, **109.5 KB** flash
- **Hardware Interface:** INMP441 I2S digital microphone driving GPIO 11, 12, 13 LEDs
- **Live Project:** [Edge Impulse Studio #1061475](https://studio.edgeimpulse.com/studio/1061475)
